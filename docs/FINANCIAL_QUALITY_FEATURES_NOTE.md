# Financial Quality Features Note

Last updated: 2026-05-10

This note documents the exploratory cash-flow and financial-quality features generated by `scripts/modeling/run_exploratory_target_lab.py`.

The features are derived from existing SEC fields already present in the production panel. They are not written into the frozen production panel during this extension pass.

## Feature Definitions

| Feature | Definition | Interpretation |
| --- | --- | --- |
| `cfo_assets` | `cash_flow_operating / total_assets` | Operating cash flow scaled by balance-sheet size. |
| `cfo_margin` | `cash_flow_operating / total_revenue` | Cash-flow conversion relative to revenue. |
| `accruals_assets` | `(net_income - cash_flow_operating) / total_assets` | Accounting earnings not supported by operating cash flow. |
| `working_capital_assets` | `(current_assets - current_liabilities) / total_assets` | Working-capital position scaled by assets. |
| `cash_to_current_liabilities` | `cash_equivalents / current_liabilities` | Cash liquidity against near-term obligations. |
| `capex_intensity_assets` | `capex / total_assets` | Capital expenditure intensity relative to assets. |
| `capex_intensity_revenue` | `capex / total_revenue` | Capital expenditure intensity relative to revenue. |
| `debt_to_cfo` | `(long_term_debt + short_term_debt) / positive cash_flow_operating` | Debt burden relative to positive operating cash flow. |

## Null And Extreme-Value Policy

- Division by zero is converted to null.
- Missing source values remain null.
- `debt_to_cfo` is only computed when operating cash flow is positive, because debt divided by zero or negative operating cash flow is not a stable coverage ratio.
- Derived feature values with absolute value above 100 are set to null before modeling, matching the production panel's conservative derived-feature cleanup policy.

## Thesis Use

These features are scientifically useful because they separate accounting profitability from cash-flow-supported profitability. They should be described as exploratory robustness features unless the final decision report promotes them into the production feature set.

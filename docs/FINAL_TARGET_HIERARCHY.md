# Final Target Hierarchy

Updated: 2026-05-10

## Decision

The thesis should use a target hierarchy, not a single overburdened target.

This solves two problems:

- strict formal distress is clean but rare;
- "success and failure factors" is broader than bankruptcy alone.

## Final Story

The thesis results should be written in this order:

1. Strict legal distress is a clean but rare benchmark.
2. Broader financial pressure is the main production failure-factor target.
3. Missing-aware success/resilience is empirically strong.
4. Validated secondary outcomes add relative resilience, stress resilience, recovery, and cash-flow-supported success dimensions.
5. Robustness extensions add dynamic peer catch-up and durable long-horizon resilience as sensitivity views.
6. Firm fundamentals, ratios, and deterioration dominate.
7. Macro regimes and global events contextualize market shifts and sector behavior.

## Productionization Rule

If a target is used as a final thesis target, one of these must be true:

- it exists as a production panel column; or
- it is explicitly labeled as an experiment-output target and all reported metrics come from saved experiment reports.

No target should be described as productionized unless it is generated by the production panel builder and survives the standard audit/model rerun.

Current productionized final targets:

- `distress_next_4q`;
- `failure_pressure_conservative_v2_next_4obs`;
- `success_resilience_next_4q`.

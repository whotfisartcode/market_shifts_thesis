## Method

- Base models are trained on the train period only.
- Candidate model choice uses validation-period PR-AUC.
- Probability calibration uses validation-period predictions only.
- The selected calibrator is chosen by validation Brier score.
- Test-period metrics are reported only after model and calibrator choices are fixed.
- Ranking diagnostics use the selected calibrated probability on the validation and test splits.

This means the test period is not used for model selection, threshold choice, or calibrator choice.

## Ranking Interpretation

The production failure-pressure model has strong alert-list behavior: the top 10% of test rows captures 73.7% of positives with 73.9% precision. The strict distress model remains a rare-event benchmark: the top 1% has 18.6% precision and 11.4x lift, but recall is low because formal distress positives are sparse.

For validated secondary production targets, top-ranked rows are highly concentrated in positives. This supports dashboard ranking and case-review use, but not causal interpretation. Stress resilience, quality success, and persistent resilience have high positive base rates, so their lift is more modest even when precision is high.

The robustness-extension targets should be interpreted asymmetrically. `persistent_resilience_next_6obs` is a strong long-horizon sensitivity result. `sector_relative_improvement_next_4obs` has useful top-rank lift and clear theoretical value, but its calibrated test PR-AUC is materially lower than the four validated secondary outcomes, so it should remain exploratory robustness rather than a headline analytical outcome.

The separate robustness-extension target audit passed all blocking invariants. It supports the current hierarchy but does not remove the scientific caveats: sector-relative improvement is OR-based over ROA/net margin and has a small number of tiny peer-group labels; persistent resilience strongly overlaps with the four-observation success target.

## Interpretation Rule

Calibrated probabilities may be described as validation-calibrated model probabilities. They should not be described as true event probabilities in a live forecasting system, because the panel is historical, non-live, and missingness/source coverage are material.
